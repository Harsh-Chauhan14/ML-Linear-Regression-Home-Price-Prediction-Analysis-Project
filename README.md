# ML-Linear-Regression-Home-Price-Prediction-Analysis-Project


# Project Overview

This project focuses on predicting house prices using Machine Learning techniques. A Linear Regression model is built after performing data cleaning, preprocessing, and feature selection on a real estate dataset.

 # Dataset Information

The dataset contains 34,000+ records with multiple features such as:
		Suburb, Address, Type
		Rooms, Bedroom, Bathroom, Car
		Distance, Landsize, BuildingArea
	 YearBuilt, Regionname, Propertycount



  # Data Preprocessing
	•	Handled missing values (drop/fill)
	•	Converted categorical variables
	•	Selected important features
	•	Removed unnecessary columns

# Model Used
	•	Linear Regression (from Scikit-learn)


# Steps Performed
	1.	Data Loading
	2.	Data Exploration (data.info(), describe())
	3.	Data Cleaning
	4.	Feature Engineering
	5.	Train-Test Split
	6.	Model Training (LinearRegression)
	7.	Model Evaluation (R², RMSE, MAE)
  
# Model Performance

From the model evaluation:
	•	R² Score (Test): ~0.67
	•	R² Score (Overall): ~0.53
	•	RMSE: ~367,776
	•	MAE: ~234,922
